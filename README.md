# PcismoMaster

Versão 0.2.3. Consulte [CHANGELOG.md](CHANGELOG.md), [CONTRIBUTING.md](CONTRIBUTING.md) e [AGENTS.md](AGENTS.md). Antes de implementar, consulte as atualizações do origin e compare o histórico remoto.

Abra dist\PcismoMaster.exe. A interface principal é a base ResetExplode. O grupo OTIMIZAÇÃO fica abaixo de MAKER; a página Inicialização do Windows permite pausar o Windows Update por 365 dias, restaurar os seis valores anteriores e abrir as configurações do Windows Update. A pausa inclui correções de segurança e pode ser limitada pelo Windows. Nenhum ajuste é aplicado automaticamente.

A central separada foi retirada do fluxo. Licenças e créditos preservados em LICENSE e licenses/Ultimate-LICENSE.txt. O motor mantém backups em %LOCALAPPDATA%\PcismoMaster\ModuleBackups.

OTIMIZAÇÃO contém a página Inicialização do Windows, com o ajuste Windows Update. A pausa deriva do Ultimate (licença MIT em licenses).
